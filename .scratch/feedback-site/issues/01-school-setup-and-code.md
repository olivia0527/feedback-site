# 01: 학교 설정 및 학교 코드 공유

**What to build:** 선생님이 학교를 설정하고, 학생이 수업에 들어갈 때 사용할 학교 코드를 확인할 수 있도록 한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 브라우저에서 선생님 화면으로 전환할 수 있다.
- [ ] 학교 이름을 입력하고 저장하면 입력한 학교 이름이 화면에 표시된다.
- [ ] 저장된 학교 코드가 선생님 화면에 표시된다.
- [ ] 학생 화면에서 학교 코드를 입력할 수 있는 입장 영역이 보인다.
