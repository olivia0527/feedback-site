# 05: 수정 글 재제출 및 반복 피드백

**What to build:** 학생이 피드백을 반영해 글을 수정하고 다시 제출하며, 선생님이 최신 수정 글을 확인하고 다시 피드백할 수 있도록 한다.

**Blocked by:** 04 선생님 피드백과 학생의 이전 글 확인

**Status:** ready-for-agent

- [ ] 학생 화면에서 이전 글과 피드백을 확인한 뒤 글을 수정할 수 있다.
- [ ] 수정 글을 다시 제출하면 선생님 화면에 최신 수정 글로 표시된다.
- [ ] 이전 글과 수정 글이 학생 화면에서 구분되어 보인다.
- [ ] 선생님이 수정 글에 다시 피드백을 남길 수 있다.
- [ ] 여러 차례 수정 글을 제출하고 매번 새 피드백을 남길 수 있다.
- [ ] 브라우저를 새로고침한 뒤에도 학교, 수업, 글, 피드백 기록이 화면에 남아 있다.
